## The word

**Breadcrumbing.**

In modern dating slang, breadcrumbing is when someone gives you just enough attention to keep you hooked, but never enough to actually commit. One text back, then silence for three days. Just enough hope to stop you from moving on.

That is exactly what home Wi-Fi does. One bar of signal, just enough to load the header of the page, then it drops mid-call. Then it comes back for a second — oh good, it's working! — then it's gone again. It never fully leaves, and it never fully works. It just keeps you hanging on.

## Why it fits

It is funny the moment you hear it, it is painfully true to how home Wi-Fi actually behaves, and it is a fresh angle nobody reaches for first. And as a network name? Seeing "Breadcrumbing" in your Wi-Fi list is hilarious — the router itself admitting what it is doing to you.

## How to run

```bash
python3 main.py
cat /output/entry.txt
```

The program writes `Breadcrumbing` to `/output/entry.txt` (or to `$OUTPUT_PATH` if set). No network, no dependencies, plain Python 3.
